# Pigeonworks LLC

A one-person company in Nichinan, a mountain town in Tottori, Japan (pop. ~4,000), building at the intersection of life science and physical practice: poultry breeding, hunting, home agriculture — and the AI-native software operation that supports them.

**What we publish here**

- Companion code for our nonfiction books (Amazon KDP)
- Small Go tools we use in production
- `homebrew-tap` for our CLI tools

**Writing**: eight nonfiction books on Amazon KDP, including a Japanese-sources history published in English.

**Contact**: [pigeonworks.net](https://pigeonworks.net)

> Software and AI are enablers here, not the product. We run our own company on the MCP servers we build — we are our own first customer.
